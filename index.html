Почта для работы с клиентами

Личный почтовый помощник Артёма Макаренко: чтение ответов на рабочие письма и отправка согласованных сообщений через Gmail.

Как работает приложение

Владелец подключает свой Gmail через официальную страницу согласия Google. Пароль Google приложению не передаётся. После разрешения приложение работает на сервере владельца через Gmail API.

Доступ используется для поиска ответов в рабочих переписках, анализа нужных писем и отправки сообщений по указанию владельца. Приложение предназначено для личного использования; публичной регистрации нет.

Какие разрешения нужны

  • Чтение Gmail: поиск писем и просмотр содержания выбранных переписок.
  • Отправка Gmail: отправка писем от имени владельца по его указанию.

Подробности хранения, обработки и удаления данных описаны в политике конфиденциальности.

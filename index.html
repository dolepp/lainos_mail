Рабочая почта и публикация видео

Личный помощник Артёма Макаренко: чтение ответов на рабочие письма, отправка согласованных сообщений через Gmail и загрузка собственных видео на YouTube по поручению владельца.

Как работает приложение

Владелец подключает Gmail и YouTube через официальную страницу согласия Google. Пароль Google приложению не передаётся. После разрешения приложение работает на сервере владельца через официальные API.

Доступ используется для поиска ответов в рабочих переписках, анализа нужных писем и отправки сообщений по указанию владельца. Приложение предназначено для личного использования; публичной регистрации нет.

Какие разрешения нужны

  • Чтение Gmail: поиск писем и просмотр содержания выбранных переписок.
  • Отправка Gmail: отправка писем от имени владельца по его указанию.
  • Чтение YouTube: определение подключённого канала и проверка его видео.
  • Загрузка YouTube: загрузка собственных роликов владельца с выбранными им названием, описанием и настройками видимости.

Подробности хранения, обработки и удаления данных описаны в политике конфиденциальности.

YouTube

Загрузка роликов использует YouTube API Services. Доступность публичной публикации зависит от настроек канала и проверки API-проекта YouTube. Подключение аккаунта само по себе не запускает загрузку.

Использование функций YouTube регулируется Условиями использования YouTube. Обработка данных Google также описана в Политике конфиденциальности Google.

Политика конфиденциальности

Эта политика описывает работу личного помощника «видио» с данными Gmail и YouTube владельца — Артёма Макаренко.

Доступ к данным

Подключение выполняется через Google OAuth 2.0. Приложение получает разрешения gmail.readonly и gmail.send: доступ к адресу подключённого ящика, поиску и чтению писем, а также отправке сообщений. Разрешение чтения технически позволяет читать содержимое писем и вложений; для выполнения конкретной задачи выбираются относящиеся к ней переписки.

Пароль аккаунта Google не запрашивается и не хранится. Для работы на сервере сохраняются токены доступа и обновления.

Для YouTube отдельно запрашиваются youtube.readonly и youtube.upload: проверка выбранного канала и его видео, загрузка роликов по поручению владельца. Обрабатываются идентификатор и название канала, метаданные видео и файлы, которые владелец передаёт для загрузки. Входящие токены YouTube хранятся отдельно от токенов Gmail.

Для чего используются данные

Данные используются для проверки ответов на рабочие письма, анализа выбранных переписок, подготовки ответов и отправки сообщений по указанию владельца. Приложение не предназначено для доступа к почте посторонних пользователей.

По поручению владельца выбранные письма могут обрабатываться ИИ-помощником и используемым для выполнения задачи сервисом ИИ. Передавать следует только сведения, необходимые для задачи. Данные Gmail не используются для рекламы, продажи данных или обучения обобщённых моделей ИИ.

Данные YouTube используются для выбора правильного канала, загрузки и проверки роликов. Загрузка и параметры публикации задаются владельцем. Локальные видеофайлы хранятся на время работы с ними и удаляются по поручению владельца; метаданные подключения хранятся до отключения или удаления локальных данных.

Хранение и защита

Учётные данные OAuth и токены хранятся в закрытых файлах на сервере владельца с ограничением доступа на уровне операционной системы. Они не публикуются в GitHub и на этом сайте. Соединение с Gmail API защищено HTTPS.

Результаты проверок и необходимые выдержки из рабочих переписок могут сохраняться на сервере для выполнения и проверки поручений. Полное почтовое хранилище не создаётся. Такие материалы хранятся до удаления владельцем или до завершения необходимости в них.

Для работы используются инфраструктура Google, серверный хостинг и, при анализе писем по поручению владельца, сервис ИИ. Получение доступа к Google Cloud Console или публикация этого сайта сами по себе не открывают доступ к почте.

Отзыв доступа и удаление

Владелец может в любой момент отозвать разрешения в настройках подключений аккаунта Google. После отзыва приложение не сможет обновлять доступ к соответствующим сервисам.

Чтобы удалить локальные токены, отчёты и сохранённые выдержки переписок, владелец удаляет соответствующие файлы на своём сервере либо направляет запрос на makarenkoae16@gmail.com. Отзыв доступа не удаляет ранее сохранённые локальные файлы автоматически. Исходные письма в Gmail этим действием не удаляются.

По запросу владельца локальные данные YouTube удаляются не позднее 7 дней. Удаление локальных файлов не удаляет ролики с YouTube: управление опубликованными видео доступно владельцу в YouTube Studio.

Правила Google API

Использование информации, полученной через Google API, и её передача другим приложениям должны соответствовать Google API Services User Data Policy, включая требования Limited Use. Доступ к данным ограничивается функциями почтового помощника, описанными здесь.

Функции загрузки используют YouTube API Services; применяются Условия использования YouTube и Политика конфиденциальности Google.
